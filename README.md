# Owen D. Sanborn - Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS v4.

## Features

- PhD Journey visualization showing weekly progress
- Publications and experience sections
- Dark theme with custom color palette
- Responsive design
- Deployed on GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Deployment

```bash
npm run deploy
```

This will build and deploy to GitHub Pages automatically.
